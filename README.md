# لوحة مؤيدي أصواتكم

لوحة تحكم تفاعلية (صفحة HTML واحدة) لعدد المؤيدين في كل بلد — الحملة الانتخابية 2026.

**الموقع:** https://ahmad-sarsor.github.io/aswatkom-dashboard/

## ما في اللوحة
- بطاقات ملخص: المؤيدون، الزيادة منذ التحديث السابق، الإنجاز من الهدف، اللوائح المبنية، أرقام الهواتف.
- رسم ترتيب البلدات حسب أي مقياس، التقدم نحو الهدف، توزيع المواقف، ملخص المناطق، وجدول كامل قابل للترتيب.
- فلاتر: بحث، منطقة، حجم البلد، واختيار عدة بلدات.

## تحديث البيانات
اضغط «رفع ملف إكسل جديد» في أعلى الصفحة وارفع ملف «لوحة المؤيدين» بنفس شكله. الملف يُقرأ داخل المتصفح ولا يُرسل لأي مكان؛ البيانات المرفوعة والأهداف المكتوبة يدويًا تُحفظ في متصفحك فقط.

لتغيير البيانات التي يراها كل من يفتح الموقع، عدّل مصفوفة `ORIGINAL_ROWS` في `index.html`.
